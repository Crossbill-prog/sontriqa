# Sontriqa — официальный сайт и загрузки

**Sontriqa — полностью бесплатная Windows-программа для маршрутизации звука приложений.** Без регистрации и платных версий. Добровольная поддержка автора не открывает дополнительных функций.

Этот публичный репозиторий содержит только **статический сайт**, необходимые лицензионные уведомления и (после проверки) установщики в разделе **Releases**. Исходники программы хранятся отдельно и не публикуются здесь.

## Статус

**Стабильная Sontriqa 1.0.0 опубликована 6 ноября 2026 года**: [GitHub Releases](https://github.com/Crossbill-prog/sontriqa/releases/tag/v1.0.0). Публичный сайт разрешает загрузку через `releaseHold=false` исключительно после проверки полного состава релиза и всех SHA-256. **Все 11 точных SHA-256 новой, уже принятой подписанной сборки** (EXE, Ed25519 подпись, `latest.json`, исходники MPL, уведомления, контрольные суммы, подтверждение состава сборки и двуязычные примечания) теперь закреплены в `site/release-validator.js`; старый уязвимый установщик запрещён явно. Владелец прямо разрешил публикацию; контроль SHA-256 и запрет уязвимого исторического EXE остаются действующими.

**Статус стабильной сборки:** исправленный установщик Sontriqa 1.0.0 с Tauri `2.12.3` подписан, его целостность проверена, а работоспособность на Windows подтверждена владельцем. Публичная загрузка открывается на сайте только после проверки точного комплекта из 11 опубликованных файлов.

**Модель доверия:** приложение распространяется без Windows Authenticode по решению автора, что может вызвать SmartScreen/Smart App Control; будущие обновления обязательно подписываются **Tauri Ed25519/minisign**, а release-артефакты снабжаются SHA-256. Подпись обновлений не является подписью издателя Windows. Не отключайте защиту системы ради непроверенного файла.

Технические подробности по предварительным сборкам и закрытым проблемам безопасности сохраняются в истории разработки. RC.18 не предназначена для новых установок; прежние тестовые клиенты сохраняют канал перехода на стабильную версию после её публикации.

**Текущие релизы:** стабильная `v1.0.0`, прежняя техническая `v1.0.0-rc.18` и переходный канал `updates-rc`. RC.18 не предназначена для новых установок; сам канал сохраняется для ранее установленных тестовых клиентов.

## Сайт

**Новый основной хостинг: Cloudflare Pages**, автоматическое развёртывание из публичного GitHub `Crossbill-prog/sontriqa`, ветка `main`. Статический сайт не использует серверную базу данных и API-ключи. Подключение Cloudflare к GitHub выполняется владельцем аккаунта один раз; после этого каждая правка `main` публикуется автоматически. Подробная инструкция: [`docs/CLOUDFLARE_PAGES_DEPLOY_RU.md`](docs/CLOUDFLARE_PAGES_DEPLOY_RU.md). Первое развёртывание **успешно подтверждено владельцем в панели Cloudflare**: официальный адрес сайта [https://sontriqa.pages.dev](https://sontriqa.pages.dev). Проверка фактического HTML непосредственно из этого сеанса пока недоступна; результат GitHub CI и Cloudflare Dashboard подтверждают успешную сборку. Прежний GitHub Pages остаётся резервным, но автоматическая публикация из него отключена из-за зависшего Pages deployment; workflow доступен только вручную.

**Защита:** сайт использует `releaseHold=false`, но скачивание разрешается исключительно после проверки GitHub API: 11 точных файлов, одобренный тег, контрольные суммы, состояние Stable и запрещённые исторические версии. `v1.0.0-rc.18` и `updates-rc` остаются в GitHub Releases и никуда не переезжают.

Связь с автором: **phKlestov@yandex.ru**. На сайте нет формы отправки сообщений или собственного аналитического счётчика. Добровольный перевод производится только на стороне банка.

## Сторонний код

Аудиодвижок построен на AppAudioRouter v2.3.0, MIT; уведомление размещено в `site/third-party-mit.txt`. Перечень зависимостей и notices прикладываются к каждому выпуску. Соответствующие исходники обнаруженных пяти MPL-2.0 Rust-пакетов (`cssparser@0.37.0`, `cssparser-macros@0.7.1`, `dtoa-short@0.3.5`, `option-ext@0.2.0`, `selectors@0.38.0`) представлены [на странице исходников](site/open-source.html) и должны быть приложены единым архивом к новому стабильному EXE одновременно с релизом. Архив исходников пяти MPL-пакетов опубликован вместе со стабильной версией, отдельно от исторической RC.18. Независимое юридическое заключение о названии и уведомлениях по 152-ФЗ не получалось.
