# Sontriqa — официальный канал распространения

Sontriqa — бесплатная программа для Windows для вывода звука приложений на несколько устройств одновременно и независимой регулировки громкости.

- Никаких платных функций, активаций или подписки.
- Донаты добровольны и не дают привилегий.
- Исходный код приложения находится в приватном репозитории разработчика.
- На этой публичной странице будут публиковаться только проверенные установщики и материалы для пользователей.
- До окончания тестирования стабильный установщик **не опубликован**.

## Загрузка

Официальные версии будут размещаться в [Releases](https://github.com/Crossbill-prog/sontriqa/releases). Не скачивайте установщики из неофициальных источников.

## Правовая информация

Аудиодвижок Sontriqa основан на AppAudioRouter, лицензия MIT. Лицензионные уведомления и информация о сторонних компонентах сопровождают дистрибутив. Пользовательские данные (маршруты, громкость, темы) хранятся локально.
