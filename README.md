# Sontriqa — официальный сайт и загрузки

**Sontriqa — полностью бесплатная Windows-программа для маршрутизации звука приложений.** Без регистрации и платных версий. Добровольная поддержка автора не открывает дополнительных функций.

Этот публичный репозиторий содержит только **статический сайт**, необходимые лицензионные уведомления и (после проверки) установщики в разделе **Releases**. Исходники программы хранятся отдельно и не публикуются здесь.

## Статус

Публичный стабильный установщик **ещё не опубликован**. Сайт оставляет загрузку стабильной версии принудительно выключенной через независимый `releaseHold=true`. **Все 11 точных SHA-256 новой, уже принятой подписанной сборки** (EXE, Ed25519 подпись, `latest.json`, исходники MPL, уведомления, контрольные суммы, подтверждение состава сборки и двуязычные примечания) теперь закреплены в `site/release-validator.js`; старый уязвимый установщик запрещён явно. Это **не разрешение на публичную публикацию**: до юридического допуска и отдельного решения владельца ссылка скачивания остаётся заблокированной, даже если все публичные файлы окажутся на GitHub.

**Внимание:** прежняя приватная сборка `1.0.0` на Tauri `2.11.1` затронута [GHSA-w28w-mhc8-qvjv](https://github.com/tauri-apps/tauri/security/advisories/GHSA-w28w-mhc8-qvjv) и **запрещена к публикации**. **Новый исправленный установщик** с Tauri `2.12.3` успешно подписан, его криптографическая целостность проверена, а работа на Windows подтверждена владельцем. Приватный EXE — только релиз-кандидат; **стабильная публикация остаётся на hold**, пока не завершена проверка лицензий/MPL, обработки данных и прав на имя Sontriqa. Исправленный бинарник не будет доступен через Releases до отдельного разрешения.

**Модель доверия:** приложение распространяется без Windows Authenticode по решению автора, что может вызвать SmartScreen/Smart App Control; будущие обновления обязательно подписываются **Tauri Ed25519/minisign**, а release-артефакты снабжаются SHA-256. Подпись обновлений не является подписью издателя Windows. Не отключайте защиту системы ради непроверенного файла.

**Отдельное предупреждение по RC.18:** логи Windows CI #41860539691 подтверждают Rust Tauri `2.11.5`, которая входит в затронутый диапазон [GHSA-w28w-mhc8-qvjv](https://github.com/tauri-apps/tauri/security/advisories/GHSA-w28w-mhc8-qvjv) (High). Уязвимость предполагает особые условия с контролируемым атакующим WebView; применимость к Sontriqa не установлена. **Не рекомендовать новые установки RC.18**: исправленная 1.0 проверена приватно, но пока не опубликована для общего скачивания. Уже использующим RC сохраняется возможность обновления через существующий канал после выпуска Stable.

**Текущие релизы** `v1.0.0-rc.18` и `updates-rc` — предварительные; тег `updates-rc` необходимо сохранить для уже установленных тестовых клиентов. Он не заменяется новым манифестом до публичной доступности принятой стабильной сборки.

## Сайт

GitHub Pages → `Settings → Pages → Source: GitHub Actions`. Workflow сам привязывает сайт к `Crossbill-prog/sontriqa` и выводит ссылку на последнюю стабильную версию. Дополнительного хостинга и регистрации пользователей нет.

Связь с автором: **phKlestov@yandex.ru**. На сайте нет формы отправки сообщений или собственного аналитического счётчика. Добровольный перевод производится только на стороне банка.

## Сторонний код

Аудиодвижок построен на AppAudioRouter v2.3.0, MIT; уведомление размещено в `site/third-party-mit.txt`. Перечень зависимостей и notices прикладываются к каждому выпуску. Соответствующие исходники обнаруженных пяти MPL-2.0 Rust-пакетов (`cssparser@0.37.0`, `cssparser-macros@0.7.1`, `dtoa-short@0.3.5`, `option-ext@0.2.0`, `selectors@0.38.0`) представлены [на странице исходников](site/open-source.html) и должны быть приложены единым архивом к новому стабильному EXE одновременно с релизом. Архив старой сборки нельзя выдавать за архив новой. Юридическая проверка MPL, бренда и обработки данных пока не завершена.
