Конфиденциальность

Sontriqa — бесплатная Windows-программа. В ней нет обязательной регистрации или серверного аккаунта. Настройки маршрутов и громкости сохраняются локально на компьютере пользователя; автоматически автору они не передаются.

На странице скачивания не установлены собственные аналитические счётчики и cookies. Сайт размещается на GitHub Pages; GitHub может обрабатывать технические данные посещений по своим условиям. Проверка наличия стабильной версии обращается к публичному GitHub API. Страница добровольного перевода открывается отдельно на стороне Т-Банка и обрабатывается по правилам банка.

При запуске подписанной Sontriqa программа проверяет наличие обновлений через GitHub, если с предыдущей успешной проверки прошло примерно 24 часа, а также по нажатию кнопки «Обновления». GitHub может получить технические данные запроса, включая IP-адрес. Локально сохранённые маршруты звука, громкость и журнал ошибок не отправляются в запросе проверки. Скачивание и установка обновления требуют отдельного подтверждения пользователя.

Связь с автором: phKlestov@yandex.ru. При добровольном отправлении письма адрес отправителя и текст сообщения попадают в почтовый сервис, чтобы автор мог прочитать обращение и ответить. Не отправляйте пароли, данные платёжных карт и другие лишние сведения. Для вопроса об удалении переписки напишите на тот же адрес.

Это описание относится к странице загрузки и приложению Sontriqa, не заменяет условия сторонних сервисов и не обещает отсутствия технических логов у хостинг-провайдера.
