Конфиденциальность Sontriqa

Sontriqa — бесплатная программа для Windows. Для использования не требуется регистрация. Маршруты звука и настройки громкости сохраняются локально на компьютере пользователя; разработчику они автоматически не передаются.

Этот сайт не использует собственные рекламные или аналитические счётчики и не устанавливает собственные cookies. Сайт размещается на GitHub Pages; GitHub может собирать технические данные о запросах согласно своим условиям. Для проверки наличия стабильной версии браузер запрашивает публичный GitHub API.

При запуске подписанной Sontriqa программа проверяет наличие обновлений через GitHub, если с предыдущей успешной проверки прошло примерно 24 часа, а также по нажатию кнопки «Обновления». GitHub может получить технические данные запроса, включая IP-адрес. Локально сохранённые маршруты звука, громкость и журнал ошибок не отправляются в запросе проверки. Скачивание и установка обновления требуют отдельного подтверждения пользователя.

При добровольном переходе на страницу поддержки пользователь покидает сайт Sontriqa. Платёжные данные обрабатываются банком, а не Sontriqa.
