## Точная последовательность

1. GitHub Actions по специальному `push` создаёт **только приватный черновик релиза** `v1.0.0` в публичном репозитории. Черновик не доступен как общедоступная загрузка.
2. В интерфейсе GitHub → `Crossbill-prog/sontriqa` → Releases → черновик `v1.0.0` загрузить **ровно 11 файлов** из подтверждённого ZIP, каждый с исходным именем. Нельзя добавлять приватный `REPRO_LOCKFILES_PRIVATE.zip`, мастер-бэкап или старый установщик.
3. Проверить, что имена и SHA-256 совпадают с `docs/SONTRIQA_1_0_0_RELEASE_MANIFEST.json`. До публикации должны быть доступны исходники MPL: `SELECTORS_0.38.0_MPL_SOURCE.zip` и уведомление `MPL_SOURCE_AVAILABILITY.txt`.
